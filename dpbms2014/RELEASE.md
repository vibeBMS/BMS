Entries of 合作！DPBMS差分大会, as their authors published them (unmodified archives). The entries are DP charts (差分) for existing songs: each needs its song, which is not part of the event.

- `NNN.zip` / `.rar` / `.7z`: work No.NNN on the [event venue](https://manbow.nothing.sh/event/event.cgi?action=List_def&event=94); the original file name is shown as the label.
- `NNN+K.*`: an add-on the author published separately.
- `index.json`: every work with its files.

Redistribution follows the event's rules (「配布規定」: package distribution by the organizer or volunteers, the archive unaltered). Authors: to have a work removed, open an issue. 削除をご希望の作者の方は Issue でお知らせください。
